# Сайт и форма отзывов

Все внешние адреса сайта лежат в начале `docs/site.js`, в объекте `CONFIG`:

- `REPO` – `владелец/имя` репозитория на GitHub (сейчас `Forecastych/DeskPartner`, это предположение).
  Из него строятся ссылки «Скачать», Issues, лицензия и исходники.
- `FORM_URL` – адрес Google Формы «DeskPartner feedback». Пустая строка – на сайте заглушка
  «форма скоро появится».

Если репозиторий назовётся иначе, поправьте ещё адрес сайта в `.github/ISSUE_TEMPLATE/config.yml`.

## Google Форма

Форма уже есть: «DeskPartner feedback» в аккаунте автора, ответы падают в Google Таблицу
«DeskPartner feedback (responses)». Шаги ниже – если её придётся пересоздать.

1. Откройте https://forms.google.com, создайте пустую форму «DeskPartner feedback / Отзыв о DeskPartner».
   Сайт двуязычный, поэтому и вопросы на двух языках, английский первым.
2. Добавьте вопросы, ни один не делайте обязательным:
   - What you liked / Что понравилось – «Текст (абзац)»;
   - What gets in the way / Что мешает или бесит – «Текст (абзац)»;
   - Idea / Идея – «Текст (абзац)»;
   - How to reach you (optional) / Как с вами связаться (необязательно) – «Текст (строка)».
3. Вкладка «Настройки» → «Ответы»:
   - «Собирать адреса электронной почты» – **не собирать**;
   - «Ограничить одним ответом» – **выключить** (иначе форма потребует вход в Google);
   - если форма в рабочем аккаунте Google Workspace, выключите «Только для пользователей …».
   Проверка: откройте ссылку на форму в окне инкогнито – она должна открыться без входа.
4. Вкладка «Ответы» → значок Таблиц «Связать с Таблицами» → «Создать таблицу».
   Новые отзывы будут сами появляться строками в этой Google Таблице.
5. Кнопка «Опубликовать», доступ «По ссылке». Без публикации форма ответы не принимает.
   Затем кнопка «Отправить» → вкладка со значком `< >` («Встроить HTML»). В коде будет
   `<iframe src="https://docs.google.com/forms/d/e/…/viewform?embedded=true" …>`.
   Скопируйте **только адрес** из `src="…"`. Короткая ссылка `forms.gle/…` не подойдёт:
   сайт встраивает только полный адрес `https://docs.google.com/forms/…`.
6. Вставьте адрес в `docs/site.js`:

   ```js
   FORM_URL: 'https://docs.google.com/forms/d/e/…/viewform?embedded=true',
   ```

   Если `?embedded=true` в конце забыли, сайт допишет сам.

## GitHub Pages

1. Залейте репозиторий на GitHub с папкой `docs/` в ветке `main`.
2. Репозиторий → **Settings** → **Pages**.
3. **Source**: «Deploy from a branch»; **Branch**: `main`, папка `/docs` → **Save**.
4. Через минуту-две сайт появится по адресу `https://<владелец>.github.io/<репозиторий>/`
   (для `Forecastych/DeskPartner` это `https://forecastych.github.io/DeskPartner/`).

Пустой файл `docs/.nojekyll` отключает обработку Jekyll: страницы отдаются как есть.

## Issues

Шаблоны лежат в `.github/ISSUE_TEMPLATE/`: «Отзыв» и «Баг», пустой issue без шаблона отключён.
Шаблоны ставят метки `feedback` и `bug`: `bug` в новом репозитории уже есть, метку `feedback`
создайте сами (Issues → Labels → New label), иначе она просто не поставится.

## Картинки

Кошки в `docs/img/` сгенерированы из кадров `src/lib/sprite.ts` и анимированы внутри SVG.
Если поменяется спрайт, их надо перегенерировать тем же способом: каждый кадр позы –
отдельная группа `<g>` из прямоугольников по палитре `PALETTE`.
